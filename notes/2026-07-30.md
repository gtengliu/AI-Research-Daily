1. **标题：TurboVLA: Real-Time Vision-Language-Action Model at 32 Hz on an RTX 4090 with <1 GB VRAM**
   - **简称：TurboVLA**
   - **领域：实时 VLA / 低显存推理 / 机器人操作**
   - **论文：** https://arxiv.org/abs/2607.27205
   - **项目：** https://H-EmbodVis.github.io/TurboVLA（Homepage 200）
   - **代码：** https://github.com/H-EmbodVis/TurboVLA（README/Homepage 200）
   - **评测：** 仿真 benchmark 为 LIBERO 四套任务与 RoboTwin 2.0 50 个双臂任务；LIBERO 每任务 50 rollouts，共 2,000 trials，RoboTwin clean setting 每任务 100 rollouts。真机为真实机器人平台部署验证，论文披露连续 7-DoF 单臂与 14 维双臂动作设置；机器人本体、末端型号和真实相机位姿数量正文未完整披露。
   - **算力：** 训练使用 4×RTX 4090 GPUs；推理在单 RTX 4090 上 31.2ms、32Hz、<1GB VRAM。
   - **解读：** TurboVLA 把传统 V→L→A 改成 V+L→A，用轻量文本编码和跨注意力直接预测动作块。贡献是把 VLA 推到消费级 GPU 实时闭环；局限是真机硬件细节披露不足。复现建议先跑 LIBERO 2,000 trials 和延迟测量。

2. **标题：RL$^2$-VLA: Adaptive RL Latent Compositional Steering with Test-Time Scaling for Vision-Language-Action Models**
   - **简称：RL2-VLA**
   - **领域：VLA test-time scaling / RL latent steering / OOD 操作**
   - **论文：** https://arxiv.org/abs/2607.26991
   - **项目：** https://rl2-vla.github.io（Homepage 200）
   - **代码：** 正文关联 HuggingFace 模型页；未披露稳定 GitHub 仓库
   - **评测：** 仿真 benchmark 为 SIMPLER 与 PolaRiS，报告 OOD 成功率最高提升 +17.3%。真机为 PiperX manipulator + RealSense D405 camera，共 1 个相机位姿；末端执行器型号正文未完整披露，真实任务成功率较最强 baseline 平均提升 +17.5%。
   - **算力：** RL policies 在 2×NVIDIA L40S GPUs 上训练 500k-1M steps。
   - **解读：** RL2-VLA 在失败预测触发时才把 RL latent policy 与 frozen VLA flow 组合，缓解采样候选同质化。贡献是把 test-time scaling 做成自适应干预；局限是依赖失败检测器。复现应固定 CoVer/π0/PolaRiS 协议。
