1. **标题：CoTinyVLA: Chain-of-Thought Distillation for a Sub-Billion-Parameter Vision-Language-Action Model**
   - **简称：CoTinyVLA**
   - **领域：小型 VLA / CoT 蒸馏 / LIBERO-Plus 鲁棒性**
   - **论文：** https://arxiv.org/abs/2607.25487
   - **项目：** https://github.com/BrainJellyPie/CoTinyVLA（README/Homepage 200）
   - **代码：** https://github.com/BrainJellyPie/CoTinyVLA（README 200）
   - **评测：** 仿真 benchmark 为 LIBERO-Plus，覆盖 Spatial/Object/Goal/Long 四套、10,030 个七维扰动任务；LIBERO 使用 Franka Panda 仿真本体，末端为夹爪，输入为 8 帧 third-person + 8 帧 wrist 双视角历史、8 维 EEF/gripper proprioception。无真机实验，真实机器人本体、末端和相机位姿数量不适用。

   - **解读：** CoTinyVLA 用双视角时序输入、35B 教师的层级 CoT 和指令改写，把 0.9B 模型推到 LIBERO-Plus 强鲁棒。贡献是证明监督结构可部分替代尺度；局限是只在单仿真 embodiment。复现建议先锁定相机帧标记与 paraphrase 数据。

5. **标题：$π\mathbf{R}^2$: Reactive Real-time Flow Policies**
   - **简称：piR2**
   - **领域：实时 VLA 推理 / flow policy / 低延迟闭环控制**
   - **论文：** https://arxiv.org/abs/2607.26055
   - **项目：** https://pi-r2-flow.github.io/（Homepage 200）
   - **代码：** 项目页核验可访问；PDF 未单列 GitHub 仓库
   - **评测：** 仿真 benchmark 为 Leap Cube Reorientation，4 个 PPO expert seed 生成 200 条 50Hz demonstrations，动作空间 16 维 relative joint commands，每 cell 100 episodes。真机为 6-DoF xArm6 + 12-DoF XHand，单个 overhead 640×480 RGB camera，共 1 个相机位姿；四项 dexterous tasks 分别采集 200/300/300/100 teleop demos，25Hz 控制。
   - **算力：** 仿真训练 1×A5000；真实 fine-tune 用 8×NVIDIA RTX A5000/A6000，部署 baseline 用 1×A5000，piR2 用 2×A5000 分离 slow VLM 与 fast DiT。
   - **解读：** piR2 把慢视觉语言通道和快 proprio/action denoise 通道拆开，让大 VLA 以 25Hz 新观测闭环重规划。贡献是现有 GR00T-N1.7 可微调成实时策略；局限是需要双 GPU 部署。复现建议先复刻延迟 tick 评测。

   - **论文：** https://arxiv.org/abs/2607.26056
   - **项目：** 正文未披露
